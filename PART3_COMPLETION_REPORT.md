## Deployment Checklist for Production

Before deploying to a real domain, ensure:

1. **Copy & edit env files:**
   ```bash
   cp .env.example .env                    # Frontend
   cp backend/.env.example backend/.env    # Backend
   ```

2. **Set required production values in `backend/.env`:**
   - `JWT_SECRET_KEY=<32+ char random string>` (generate: `python -c "import secrets; print(secrets.token_urlsafe(32))"`)
   - `CORS_ORIGINS=https://your-domain.com,https://www.your-domain.com`
   - `DATABASE_URL=sqlite:////absolute/path/to/climatify.db` (or PostgreSQL URL)
   - `ADMIN_BOOTSTRAP_PASSWORD=<strong password>`
   - `UPLOAD_FOLDER=/absolute/path/to/uploads`
   - `FRONTEND_DIST=/absolute/path/to/dist`
   - `FLASK_ENV=production` (or omit — must NOT be `development`)

3. **Set frontend `VITE_API_BASE_URL`** to `https://your-api-domain.com/api` (or use Vite proxy).

4. **Run migrations & seed:**
   ```bash
   cd backend
   AUTO_CREATE_TABLES=true flask seed-admin
   # or: flask db upgrade && flask seed-admin
   ```

5. **Build frontend:**
   ```bash
   npm run build
   ```

6. **Serve via reverse proxy** (nginx/Caddy) with TLS — Flask binds to 127.0.0.1:5000 internally.
